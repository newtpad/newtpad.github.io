    Setup Violentmonkey Companion ✕

    Browsers block extensions from directly opening scripts from local file:/// paths. Choose one of the quick options below:

    Option A: 1-Click Clipboard (Fastest) Copy the script code to clipboard, open Violentmonkey from your extensions toolbar, click + (New), and paste.
    Option B: Drag & Drop Download the file and drag it directly into the open Violentmonkey popup window. ⬇ Download newtpad.user.js
    💡 Once hosted live on https://newtpad.github.io, 1-click install works natively without these steps.
